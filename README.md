# MiniBanco

## Sobre o projeto

MiniBanco é uma aplicação de console desenvolvida em C# com .NET para simular operações bancárias e analisar a saúde financeira das contas.

## Funcionalidades

- Abertura de contas corrente, poupança e salário.
- Depósitos e saques.
- Fechamento mensal.
- Registro de transações.
- Análise financeira com pontuação e classificação.
- Tratamento de saldo insuficiente.

## Tecnologias

- C#
- .NET
- Git e GitHub

## Como executar

Com o SDK do .NET instalado, abra o terminal na pasta do projeto e execute:

```bash
dotnet run
```

## Principais arquivos

- `Program.cs`: menu principal.
- `Conta.cs`: classe base das contas.
- `ContaCorrente.cs`: regras da conta corrente.
- `ContaPoupanca.cs`: regras da conta poupança.
- `ContaSalario.cs`: regras da conta salário.
- `Transacao.cs`: registro de transações.
- `MotorAnalise.cs`: análise financeira.
